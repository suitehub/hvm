# HVM Performance Pixel

Quero que você desenvolva uma landing page para a HVM Digital Performance utilizando a imagem de referência que estou anexando como referência visual principal e obrigatória.

REGRA MAIS IMPORTANTE

NÃO REINTERPRETE O DESIGN.

Quero que a página desenvolvida fique o mais idêntica possível à imagem de referência.

A imagem não é apenas uma inspiração.

Ela deve ser tratada como o layout visual que precisa ser reproduzido.

Preserve fielmente:

Estrutura

Ordem das seções

Composição

Proporções

Espaçamentos

Hierarquia visual

Posicionamento dos elementos

Tamanho relativo dos elementos

Estilo dos cards

Tipografia

Contraste

Fundo

Efeitos de iluminação

Elementos gráficos

Estilo das imagens

CTAs

Separações entre seções

Estética geral

Linguagem visual

Sensação de profundidade

Uso de azul e ciano

Atmosfera tecnológica e orientada a performance

Não crie uma nova versão do design.

Reproduza o design apresentado na imagem.

1. IDENTIDADE DA HVM

Empresa:

HVM Digital Performance

A página deve transmitir:

Performance

Marketing digital

Dados

Crescimento

Estratégia

Tecnologia

Conversão

Profissionalismo

Escala

A estética deve ser predominantemente:

dark + tecnológica + premium + performance + azul/ciano.

Utilize fundo predominantemente preto ou azul extremamente escuro.

Os elementos de destaque devem utilizar azul elétrico/ciano, mantendo o mesmo comportamento visual observado na imagem.

2. HERO — NÃO ALTERAR

A primeira seção deve permanecer EXATAMENTE como está apresentada na referência.

Essa é uma regra crítica.

Não altere a estrutura da Hero.

Não altere a composição.

Não altere a posição dos elementos.

Não altere a hierarquia.

Não transforme a Hero em outro layout.

Não substitua a composição por uma Hero tradicional de agência.

A Hero deve manter:

Navbar no topo

Logo HVM

Menu horizontal

CTA no canto superior direito

Headline grande à esquerda

Palavra/trecho destacado em azul

Texto de apoio

Botões

Pequenos diferenciais abaixo dos CTAs

Grande imagem central/direita

Pessoa de costas diante dos monitores

Monitores com dashboards

Cards flutuantes de métricas

Elemento circular azul ao fundo

Barra inferior de parceiros/credibilidade

A Hero é intocável.

Se precisar adaptar para responsividade, faça apenas as adaptações necessárias para manter a mesma composição e intenção visual no mobile.

3. A PARTIR DA SEGUNDA SEÇÃO

A partir da segunda seção, siga exatamente a estrutura visual da imagem de referência anexada.

A referência possui uma estética mais editorial e visual, com blocos grandes de conteúdo, imagens tecnológicas, textos posicionados assimetricamente, elementos luminosos e seções com bastante espaço negativo.

Não transforme tudo em uma sequência de cards.

Não faça uma landing page SaaS genérica.

Não use o padrão:

Hero → 3 cards → 6 cards → depoimentos → FAQ.

Siga a composição da referência.

4. SEGUNDA SEÇÃO — GRANDE BLOCO VISUAL

Depois da Hero, crie uma seção semelhante à referência.

Ela deve possuir:

Texto grande à esquerda

Headline em branco

Palavra ou trecho estratégico destacado em azul

Texto explicativo

CTA

Indicadores/números em pequenos blocos

Elemento visual tecnológico grande ocupando a área direita

O elemento visual deve transmitir:

crescimento + estratégia + performance + dados.

Utilize uma composição visual sofisticada, com iluminação azul/ciano.

Não utilize uma imagem genérica de banco de imagens.

5. SEÇÃO COM LAPTOP / PERFORMANCE

Reproduza a seção seguinte da referência:

Imagem grande de laptop/dashboard em um dos lados.

Texto no lado oposto.

Headline grande.

Destaque azul.

Parágrafos curtos.

CTA.

A imagem deve possuir iluminação/glow azul para integrar-se ao fundo.

A composição deve manter o mesmo equilíbrio visual da referência.

6. SERVIÇOS

Crie a seção de serviços seguindo o estilo visual da referência.

Não use cards brancos.

Utilize:

Fundo escuro

Bordas discretas

Azul/ciano

Ícones lineares

Tipografia branca

Pequenos detalhes luminosos

Cantos levemente arredondados

Os cards devem parecer parte da mesma interface.

Serviços devem ser baseados no posicionamento real da HVM.

Não invente serviços que não façam sentido para a empresa.

7. SEÇÃO “O QUE A HVM FAZ?”

Reproduza o conceito visual da seção de processo/explicação da referência.

Utilize uma composição horizontal com pontos conectados por linhas.

Cada ponto representa uma etapa ou função.

A estrutura deve ter:

01
02
03
04
05

com pequenos textos explicativos.

Utilize azul/ciano nos elementos de conexão.

O resultado deve parecer uma espécie de timeline estratégica.

8. PROVA SOCIAL

Crie uma seção de depoimentos visualmente semelhante à referência.

Utilize:

Fundo escuro

Cards horizontais

Foto de perfil

Nome

Avaliação

Ícone do Google

Texto do depoimento

Indicador de carousel

NÃO INVENTE DEPOIMENTOS.

Caso os depoimentos reais não estejam disponíveis, deixe conteúdo claramente preparado para substituição.

9. CLIENTES / EMPRESAS

Crie uma seção de empresas/clientes seguindo a mesma linguagem visual da referência.

Logotipos devem aparecer em uma composição limpa e horizontal.

Não invente empresas.

Se os logos reais ainda não forem fornecidos, utilize placeholders claramente identificáveis.

10. SEÇÃO DE AUTORIDADE

Crie um bloco visual semelhante ao apresentado na referência.

A seção deve comunicar:

A HVM trabalha para gerar crescimento real.

Utilize:

Texto forte

Números

Indicadores

Elementos gráficos

Imagem ou composição visual

Fundo escuro

Azul/ciano

Não invente números.

Utilize placeholders caso os dados reais ainda não estejam disponíveis.

11. BLOCO DE CTA

Reproduza a ideia do grande CTA da imagem.

Crie um bloco visual forte com:

Headline

Subheadline

CTA

Elemento visual tecnológico

Destaques azuis

Fundo escuro

Glow

O CTA deve ser visualmente importante.

O usuário deve entender claramente o próximo passo.

12. FAQ

A seção de perguntas frequentes deve seguir o mesmo estilo da referência.

Utilize accordions.

Cada pergunta deve ter:

Texto

Indicador “+”

Hover

Animação suave ao abrir

Não utilize cards enormes.

Mantenha a composição compacta.

13. FOOTER

O footer deve seguir a referência.

Inclua:

Logo HVM

Pequena descrição

Navegação

Serviços

Contato

Redes sociais

Direitos autorais

Mantenha o fundo escuro e a separação visual discreta.

14. TIPOGRAFIA

A tipografia precisa seguir visualmente a referência.

Priorize:

Sans-serif moderna

Títulos grandes

Alto contraste

Peso forte nos headings

Textos menores e discretos

Não use fontes decorativas.

A tipografia deve transmitir tecnologia e performance.

15. CORES

A paleta deve ser predominantemente:

Preto / Azul extremamente escuro / Branco / Azul elétrico / Ciano.

O azul deve ser utilizado nos mesmos locais em que a referência utiliza seus elementos de destaque.

Não espalhe azul aleatoriamente pela página.

O azul deve funcionar como:

cor de ação + destaque + performance + tecnologia.

16. EFEITOS

Utilize efeitos semelhantes à referência:

Glow azul

Gradientes muito sutis

Iluminação ambiente

Sombras suaves

Transparência discreta

Linhas luminosas

Elementos tecnológicos

Depth

Blur controlado

Porém:

não exagere nos efeitos.

A página precisa continuar profissional.

17. RESPONSIVIDADE

Desktop deve ser a prioridade para reproduzir a imagem de referência.

Depois adapte para:

Tablet

Mobile

No mobile, não simplesmente reduza tudo.

Reorganize os elementos preservando:

Hierarquia

Identidade

CTA

Imagens

Ordem das informações

Impacto visual

18. INTERAÇÕES

A página deve ser funcional.

Implemente:

Menu

Scroll suave

Botões

Hover

FAQ accordion

Carrossel de depoimentos, se necessário

CTA para WhatsApp

Formulário, caso utilizado

Microinterações

As animações devem ser discretas e premium.

19. TECNOLOGIA

Utilize:

React

TypeScript

Tailwind CSS

Componentização

Código limpo

Responsividade

Acessibilidade

Performance

Não adicione bibliotecas desnecessárias.

20. REGRA CONTRA “MELHORIAS” AUTOMÁTICAS

Isso é importante:

Não quero que você altere a composição porque considera que outra solução seria mais moderna, bonita ou eficiente.

A imagem anexada representa a direção visual aprovada.

Se você identificar uma oportunidade de melhoria, não altere automaticamente.

Mantenha a referência.

21. FIDELIDADE VISUAL

Compare constantemente a implementação com a imagem.

Verifique:

Altura relativa das seções

Espaçamento vertical

Largura do conteúdo

Posição das imagens

Tamanho dos títulos

Tamanho dos cards

Distância entre elementos

Contraste

Intensidade do glow

Distribuição do azul

Alinhamento

Densidade visual

Quero que alguém consiga colocar a imagem de referência ao lado do site e reconhecer imediatamente que se trata do mesmo design.

22. NÃO FAÇA

NÃO:

Crie outro Hero

Mude o Hero

Troque a composição

Use layout genérico de agência

Coloque excesso de cards

Use gradiente roxo

Use glassmorphism exagerado

Use imagens aleatórias

Invente clientes

Invente depoimentos

Invente resultados

Invente números

Troque o azul por outra cor

Simplifique excessivamente as seções

Transforme tudo em blocos centralizados

Faça uma versão “inspirada”

Quero uma reprodução fiel da referência.

23. RESULTADO ESPERADO

O resultado final deve parecer:

a mesma landing page da imagem de referência, transformada em um site real, funcional, responsivo e interativo para a HVM Digital Performance.

A imagem anexada é a referência visual principal.

Prioridade máxima: FIDELIDADE VISUAL.

Não quero uma interpretação.

Quero uma implementação extremamente próxima da referência.
